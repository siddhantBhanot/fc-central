# Jenkins Build Pipeline Overview

## Build Pipelines

There will be a build pipeline for every service.

This includes:

- UI services
- Backend services

## Build Pipeline Naming

Example for a backend service build:

`home-loan-home-loan-orchestrator-build`

Service names can vary.

Examples of build pipeline naming formats:

- `service-name-orchestrator-build`
- `servicename-ui-build`
- `servicename-build`

The service name can vary depending on the service.
